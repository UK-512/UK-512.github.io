01. About

I'm a Cloud Security Engineer with experience in cloud infrastructure, cybersecurity, DevOps, and AI-driven automation. At SecureKloud Technologies I design and run production environments on Google Cloud for enterprise clients in banking, housing finance, and logistics — end to end, from VPC networking and IAM to Cloud Run, Cloud SQL, load balancing, and domain cutover.

My work focuses on designing secure cloud environments, automating infrastructure, and strengthening enterprise security using AWS, Azure, GCP, Terraform, Docker, Kubernetes, Wazuh, Microsoft Sentinel, and modern DevSecOps practices — plus the FinOps discipline (billing pipelines, cost modelling) that keeps platforms sustainable.

I believe security should be integrated into every stage of infrastructure — not added as an afterthought.
